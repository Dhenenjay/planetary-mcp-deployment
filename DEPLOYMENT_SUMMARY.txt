═══════════════════════════════════════════════════════════════════════════════
  🚀 DEPLOYMENT METHODS
═══════════════════════════════════════════════════════════════════════════════

LOCAL (Windows/Mac/Linux):
  1. Ensure Docker Desktop is running
  2. Place credentials in credentials/ee-key.json
  3. Run: docker-compose up -d --build
  4. Configure Claude Desktop (see QUICKSTART.md)

AWS EC2:
  1. Launch EC2 instance (t3.medium or larger)
  2. Install Docker & Docker Compose
  3. Upload this entire folder to server
  4. Run: docker-compose up -d --build
  5. Open port 3000 in security group
  6. Configure Claude Desktop to point to EC2 IP

AZURE/GCP:
  Same process as AWS - Docker works everywhere!
